# A counter with computed values

Write `Counter.vue`.

- A paragraph with the class `count` shows `Count: N`. It starts at 0.
- A button `Add` increases the count by 1.
- A button `Subtract` decreases it by 1. It is **disabled** when the count is 0, so the count never goes below 0.
- A button `Reset` sets it back to 0.
- A paragraph with the class `double` shows `Double: N`, where N is twice the count. Use `computed`.
- A paragraph with the class `parity` shows `even` or `odd`. Use `computed`.

Run the tests to check your component. **Start app** opens it in a browser tab, and the page reloads when you save.
