# A class of static methods

Complete the four static methods in `MathUtil.java`. `Tests.java` calls them; do not edit it.

- `int gcd(int a, int b)`: the greatest common divisor of two non-negative numbers. `gcd(7, 0)` is 7.
- `boolean isPrime(int n)`: whether `n` is prime. Numbers below 2 are not.
- `long factorial(int n)`: `n!`, with `0!` equal to 1. It must be correct up to `20!`, which does not fit in an `int`.
- `int sumDigits(long n)`: the sum of the decimal digits of `n`. For a negative number, ignore the sign.
