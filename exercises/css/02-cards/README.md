# Boxes: a column of cards

Style `index.html` from `style.css`.

- Every element uses `box-sizing: border-box`. Use the `*` selector.
- `.page` is centred: `max-width: 600px`, top and bottom margin `0`, left and right margin `auto`.
- `.card` has `padding: 16px`, a border of `1px solid #cccccc`, `border-radius: 8px`, and a bottom margin of `24px`.
- `.card h2` has a top margin of `0`.
- `.button` is displayed as `inline-block`, with `padding: 8px 16px` (8px top and bottom, 16px left and right) and `background-color: navy`.

The tests read your CSS as it is written. Use the property names given here: for example `background-color`, not the `background` shorthand with several values.
