# Style a page with selectors

Read `index.html`, then write rules in `style.css`. Do not change the HTML.

- `body` text has the colour `#222222` and the font family `sans-serif`.
- The `h1` has the colour `navy`.
- The paragraph with the class `intro` has `font-size: 1.25rem`. The other paragraph does not.
- Links inside the `nav` have `text-decoration: none`.
- The link with the class `active` has `font-weight: bold`.
- A `nav` link under the mouse (`:hover`) has `text-decoration: underline`.
- The **first** list item has `font-weight: bold`. Use a pseudo-class: the HTML has no class for it.

The tests read your CSS as it is written. Use the property names given here: for example `background-color`, not the `background` shorthand with several values.
