# From divs to landmarks

`index.html` is built entirely from `div` elements. Rewrite it with elements that say what each part is. Keep all the text.

- The top block becomes a `header`. It contains the `h1`.
- The menu becomes a `nav` that contains a `ul` with one `li` per link.
- The content becomes one `main`.
- Each of the two posts becomes an `article`, and each post title becomes an `h2`.
- The "Read more" texts become real links: `a` elements with an `href`.
- The bottom block becomes a `footer`.
- No `div` is left in the page.
