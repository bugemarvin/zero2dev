# A price table

Build this table in the body of `index.html`:

| Plan | Price | Storage |
| --- | --- | --- |
| Basic | $5 | 10 GB |
| Pro | $12 | 100 GB |
| Team | $30 | 1 TB |

- The table has the caption `Monthly plans`.
- The header row is inside `thead`. Its three cells are `th` elements with `scope="col"`.
- The three data rows are inside `tbody`.
- In each data row the first cell is a `th` with `scope="row"`, and the other two are `td`.
