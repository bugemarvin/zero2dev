# Your first page

Write a complete page in `index.html`.

- It starts with the doctype.
- The `html` element says the language is English: `lang="en"`.
- The head has `<meta charset="utf-8">` and the title `About me`.
- The body has exactly one `h1` with the text `About me`.
- Under it, an `h2` with the text `Hobbies`.
- At least two paragraphs.

**Open preview** shows your page in a browser tab.
