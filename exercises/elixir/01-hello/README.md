# A first module

Complete the module `Hello` in `solution.ex`.

- `greet/0` returns `"Hello, world!"`
- `greet/1` takes a name and returns `"Hello, NAME!"`
- `shout/1` takes a string and returns it in upper case with an exclamation mark added: `shout("hi")` is `"HI!"`
- `sum_and_product/2` takes two numbers and returns a tuple of their sum and their product: `sum_and_product(3, 4)` is `{7, 12}`
- `halve/1` takes an integer and returns half of it as an integer, rounding down: `halve(7)` is `3`

The functions return their result. They do not print.
