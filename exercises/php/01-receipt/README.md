# A receipt

Write `solution.php`. Read three values from standard input, separated by whitespace: a product name (one word), a price and a quantity.

Print:

```text
Item: coffee
Quantity: 3
Total: 10.50
Big order
```

- The total is the price times the quantity, with two decimals.
- The last line is `Big order` when the total is 10 or more, otherwise `Small order`.

That output is for the input `coffee 3.5 3`.
