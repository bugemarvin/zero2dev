# A counter with state

Complete `Counter.jsx`.

`<Counter start={5} step={2} />` shows:

- a `<p>` with the text `Count: 5`
- a button `Add` that increases the count by `step`
- a button `Subtract` that decreases it by `step`, but never below 0
- a button `Reset` that goes back to `start`

`start` defaults to 0 and `step` to 1.

The `Subtract` button is **disabled** when the count is 0.

Run the tests to check your component. **Start app** opens it in a browser tab.
