# Your first components

Complete `App.jsx`.

1. `Footer` is a component that returns a `<footer>` element containing the text `Made with React`. Export it by name.
2. `App`, the default export, returns:
    - an `<h1>` with the text `Hello, React!`
    - a `<p>` with the CSS class `lead` and the text `This is my first component.`
    - the `Footer` component.

A component returns a single root element, so wrap the three in a `<div>` or in `<>...</>`.

Run the tests to check your component. **Start app** opens it in a browser tab.
