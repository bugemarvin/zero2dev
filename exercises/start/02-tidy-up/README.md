# Tidy a messy folder

Your working folder contains a mess of files. Tidy it:

1. Move every `.txt` file into a new folder named `text`.
2. Delete every `.tmp` file.
3. Rename `report.md` to `summary.md`.
4. Copy `photo.png` into a new folder named `backup`. The original stays where it is.
5. Make `run.sh` executable.

Run the check command once first. It creates the working folder with the files in it.
