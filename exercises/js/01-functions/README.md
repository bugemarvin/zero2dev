# First functions

Write four functions in `solution.mjs` and export each of them.

- `greet(name)` returns `Hello, NAME!`. With no argument it returns `Hello, world!`.
- `isAdult(age)` returns `true` when the age is 18 or more, otherwise `false`.
- `fizzbuzz(n)` returns `"FizzBuzz"` if `n` is divisible by 15, `"Fizz"` if by 3, `"Buzz"` if by 5, and otherwise the number as a string, such as `"7"`.
- `sum(...numbers)` returns the sum of all its arguments, and `0` when there are none.

The functions return their result. They do not print.
