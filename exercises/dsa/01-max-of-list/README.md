# Largest number

This first exercise is mainly about the input and output format that every exercise in this track uses.

**Input:** the first line holds `n`, the count of numbers (at least 1). The second line holds `n` whole numbers separated by spaces.

**Output:** the largest of the numbers.

```text
input          output
5              9
3 9 -2 7 4
```

Find it with one pass over the numbers. That is O(n).

`solution.py` already reads the input. Fill in the function. To solve it in another language, create a starter with `python3 check.py start dsa/01-max-of-list --lang java` and read standard input yourself.
