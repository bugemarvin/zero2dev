# A card, with utilities only

The page in `index.html` has no styling: the `class` attributes are empty. Fill them in. Do not write any CSS.

- The `body` has the background `bg-gray-100` and a padding of `p-8`.
- The `article` has the padding `p-6`, the background `bg-white`, the corners `rounded-lg` and the shadow `shadow-md`.
- The `h2` has the size `text-xl`, is `font-bold`, and has the colour `text-gray-900`.
- The paragraph has a top margin of `mt-2` and the colour `text-gray-600`.
- The link has `text-blue-600` and is `underline`.

**Run tests** builds the CSS with Tailwind and checks the classes on the page. **Open preview** shows the styled page, and builds again when you run or save.
