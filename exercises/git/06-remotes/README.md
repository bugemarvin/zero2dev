# Clone, commit, push

Your working folder contains `remote.git`. It plays the part of a repository on GitHub, so this exercise works offline.

1. Clone it into a folder named `mycopy`: `git clone remote.git mycopy`
2. Inside `mycopy`, create `notes.txt` and commit it.
3. Push the commit to the remote.

Afterwards `git status` inside `mycopy` should say your branch is up to date with `origin/main`.
