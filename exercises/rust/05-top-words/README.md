# Top words

Write `main.rs`. Read all of standard input and count the words, **ignoring upper and lower case**. Words are separated by whitespace.

Print the **three** most frequent words, one per line, as `word count`, in lower case. Highest count first. Words with the same count are in alphabetical order. If there are fewer than three different words, print them all.

Input:

```text
the cat and the dog and the bird
```

Output:

```text
the 3
and 2
bird 1
```
