# Number statistics

Write `main.rs`. The input is a list of whole numbers separated by spaces and newlines. The starter already reads them into `numbers`.

Print four lines:

```text
count: 4
sum: 20
max: 9
average: 5.00
```

The average has two decimals. That output is for the input `2 9 4 5`.

With no numbers, print only `count: 0`.
