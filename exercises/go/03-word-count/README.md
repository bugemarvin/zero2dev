# Word count

Write `main.go`. Read all the words from standard input. Words are separated by spaces and newlines. Count them **ignoring upper and lower case**.

Print one line per different word, as `word count`, in lower case, sorted **alphabetically**.

Input:

```text
the cat The dog
the END
```

Output:

```text
cat 1
dog 1
end 1
the 3
```

With no input, print nothing.
