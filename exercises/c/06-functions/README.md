# A small maths library

Implement the four functions declared in `mathx.h`. Write your code in `mathx.c`. Do not change `mathx.h` or `test_main.c`.

- `int gcd(int a, int b)`: the greatest common divisor of two non-negative numbers. `gcd(7, 0)` is 7.
- `int is_prime(int n)`: 1 if `n` is prime, 0 otherwise. Numbers below 2 are not prime.
- `long factorial(int n)`: `n!`, with `0!` equal to 1.
- `int fib(int n)`: the n-th Fibonacci number, where `fib(0)` is 0 and `fib(1)` is 1.

The functions **return** their result. They do not print anything.
