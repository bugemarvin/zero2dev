# First functions

Write three functions in `solution.py`. Each one **returns** its answer.

- `greeting(name)` returns the text `Hello, NAME!`, for example `Hello, Sam!`
- `to_fahrenheit(celsius)` converts a temperature: multiply by 9/5 and add 32.
- `is_even(n)` returns `True` when `n` is even and `False` otherwise.
