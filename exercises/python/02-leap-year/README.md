# Leap years and grades

Write two functions in `solution.py`.

`is_leap_year(year)` returns `True` or `False`:

- a year divisible by 4 is a leap year,
- except years divisible by 100, which are not,
- except years divisible by 400, which are.

`grade(score)` returns a letter for a score from 0 to 100:

| Score | Grade |
| --- | --- |
| 90 and above | `A` |
| 80 to 89 | `B` |
| 70 to 79 | `C` |
| 60 to 69 | `D` |
| below 60 | `F` |
