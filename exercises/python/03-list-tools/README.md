# List tools

Write four functions in `solution.py`. None of them may change the list it is given.

- `evens(numbers)` returns a new list with only the even numbers, in the same order.
- `longest(words)` returns the longest word. If several are equally long, the first of them. For an empty list, return `""`.
- `running_total(numbers)` returns a list where each element is the sum of everything up to and including that position: `[1, 2, 3, 4]` gives `[1, 3, 6, 10]`.
- `unique(items)` returns the items with duplicates removed, keeping the order in which each first appeared.
