zero2dev Setup

From zero to developer, offline.

Short lessons, then real practice in your own terminal. Every exercise has tests that tell you straight away whether your code works.

Start the first lesson

How it works

  1. Read a lesson

    Pick a track below. Each lesson explains one idea with examples you can run.

  2. Do the exercise

    Start the local app and write your code right in the lesson page. It runs on your own computer.

    $ python3 app.py

  3. Run the tests

    Press Run tests and see what passed. Prefer a terminal and your own editor? That works too.

    $ python3 check.py next
