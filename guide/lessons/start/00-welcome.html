Install: what this track needs

Quick install

One command installs everything for this track. It skips what you already have.

Ubuntu, Debian, or Ubuntu inside WSL, from the zero2dev folder:

$ ./setup/install.sh --stack core

If something does not install, the script says why and offers to try again or to install it another way.

Windows, from an Administrator PowerShell in the setup folder (it installs WSL and Ubuntu first if needed):

powershell -ExecutionPolicy Bypass -File .\install.ps1 -Stacks core

macOS has no quick install script. Use the Homebrew commands below, or let Docker run what is missing.

C compiler, Make, Git and shell tools: by hand

Ubuntu, Debian, WSL:

$ sudo apt-get update
$ sudo apt-get install -y build-essential gdb valgrind make git curl

macOS, with Homebrew:

$ xcode-select --install

Check that it works:

$ gcc --version && git --version

When the app is running, this box also shows what your machine already has.

You are in the right place

This guide assumes you know nothing about programming. If you can use a web browser and type on a keyboard, you have everything you need.

You do not need to be good at mathematics. You do not need a new computer. You do not need to be young, or "a computer person". Programming is a skill like cooking or driving: it looks like magic from outside, and it is learned by doing a little, often.

What programming is

A computer is fast and has no judgement at all. It does exactly what it is told, in order, with no idea of what you meant.

Programming is writing down instructions precisely enough for a machine to follow. Those instructions are called code, and a finished set of them is a program (or an "app").

Here is a complete program in the language Python:

name = "Sam"
print("Hello, " + name)

It stores a name, then shows Hello, Sam on the screen. In a few days you will write programs like this without thinking.

How one session works

Every lesson has the same three parts:

  1. Read. A short explanation with examples. Ten minutes, usually.
  2. Quiz. A few questions in a pop-up. You see at once whether you understood, with an explanation for each answer.
  3. Practise. An exercise where you write real code. You press Run tests, and the computer checks your work and tells you exactly what is right and what is not.

The third part is where you learn. Reading feels like progress. Typing is progress.

Which path?

On the home page you choose a path. If you are new, choose Start from zero. It takes you through:

  1. how computers run programs, and the terminal;
  2. Git, the tool that saves every version of your work;
  3. Python, a first language that reads almost like English;
  4. HTML and CSS: your first web page.

After that you will know enough to pick a direction: websites, the server side, games, automation, artificial intelligence. Each has its own path, and you can switch at any time.

You will get stuck. That is the job.

Being stuck is not a sign that you are bad at this. It is what the work is. A professional with twenty years of experience is stuck several times a day. The difference is that they have a routine for it:

  1. Read the error message. Slowly, the whole thing. It usually names the line and the problem. Beginners skip it. Do not.
  2. Check the obvious. A missing bracket, a misspelled name, a capital letter where a small one belongs.
  3. Make it smaller. Remove things until it works, then add them back one at a time.
  4. Use the hint. Every exercise has hints. After two failed tries one appears by itself.
  5. Explain it out loud, to a friend, a pet or a rubber duck. Saying what the code should do, line by line, often reveals the line that does something else.
  6. Take a break. Solutions arrive in the shower with suspicious regularity.

How to learn this well

  • A little every day beats a lot once a week. Twenty minutes is enough. The streak counter is there to help.
  • Type the examples. Do not copy and paste. Your fingers learn too.
  • Change things on purpose. What happens if you remove this line? Break it, see the error, put it back. Nothing you do in an exercise can harm your computer.
  • Do not wait to feel ready. Nobody does. Start the next lesson.

What you need on your computer

To read the lessons and do the quizzes: nothing. They work as they are.

To do the exercises, the app must be running on your computer. If you are reading this in the app, it already is. If not, the next lesson but one gets you there, step by step, for Windows, Linux and macOS.

Common worries

  • "I am too old / too young / not clever enough." No. The people who succeed are the ones who keep turning up.
  • "I do not understand everything in a lesson." Normal. Carry on. Things click three lessons later, when you use them.
  • "Everyone else already knows this." They were exactly where you are now.
  • "I broke it." Good. You are about to learn something. Press Reset and try again.
