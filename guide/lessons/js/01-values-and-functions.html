Install: what this track needs

Quick install

One command installs everything for this track. It skips what you already have.

Ubuntu, Debian, or Ubuntu inside WSL, from the zero2dev folder:

$ ./setup/install.sh --stack node

If something does not install, the script says why and offers to try again or to install it another way.

Windows, from an Administrator PowerShell in the setup folder (it installs WSL and Ubuntu first if needed):

powershell -ExecutionPolicy Bypass -File .\install.ps1 -Stacks node

macOS has no quick install script. Use the Homebrew commands below, or let Docker run what is missing.

Node.js and npm: by hand

Ubuntu, Debian, WSL:

$ curl -fsSL https://mise.run | sh
$ ~/.local/bin/mise use --global node@lts

macOS, with Homebrew:

$ brew install node

Check that it works:

$ node --version && npm --version

Or install nothing: with Docker running, the app runs JavaScript in the image node:22-slim (one download).

The node packages come from npm, once: press Download packages on the Setup page, or run python3 check.py prefetch node.

The react packages come from npm, once: press Download packages on the Setup page, or run python3 check.py prefetch react.

When the app is running, this box also shows what your machine already has.

Where JavaScript runs

JavaScript started in the browser, where it makes pages interactive. Node.js runs the same language outside the browser: on your machine and on servers. This track uses Node first, because it needs nothing but a terminal. The browser comes in lesson 10, and then React.

The app checks whether Node is already installed and uses it. If it is not, the exercises can run in a Docker container instead.

$ node --version
$ node
> 1 + 2
3
> .exit

Run a file with node file.mjs. The .mjs ending tells Node the file is a modern module, which lesson 3 explains.

Variables

const name = "Sam";      // cannot be reassigned
let count = 0;           // can be reassigned
count = count + 1;

Use const by default, and let only when the variable must change. Do not use the old var.

typeof value tells you the type as a string.

Strings

Backticks make a template literal, which can contain expressions and line breaks:

const name = "Sam";
const age = 30;
console.log(`${name} is ${age} years old`);
"hello".length              // 5
"hello".toUpperCase()       // "HELLO"
"a,b,c".split(",")          // ["a", "b", "c"]
"  hi  ".trim()             // "hi"
"hello".includes("ell")     // true
"hello".slice(1, 3)         // "el"
String(42)                  // "42"
Number("42")                // 42

Equality

Always use === and !==. The two-character == converts types before comparing, with surprising results:

1 === 1       // true
1 === "1"     // false: different types
1 == "1"      // true: avoid this

Truthy and falsy

In a condition, these count as false: false, 0, "", null, undefined and NaN. Everything else counts as true, including [] and {}.

if (name) {
  console.log("a name was given");
}

Conditions and loops

if (age >= 18) {
  console.log("adult");
} else if (age >= 13) {
  console.log("teenager");
} else {
  console.log("child");
}

for (let i = 0; i < 3; i++) {
  console.log(i);
}

const kind = age >= 18 ? "adult" : "minor";    // the conditional operator

Functions

function area(width, height) {
  return width * height;
}

The arrow function is a shorter form, used constantly:

const area = (width, height) => {
  return width * height;
};

const double = (n) => n * 2;     // one expression: no braces, no return needed

Default values and "any number of arguments":

function greet(name = "world") {
  return `Hello, ${name}!`;
}

function sum(...numbers) {       // numbers is an array of all the arguments
  let total = 0;
  for (const n of numbers) {
    total += n;
  }
  return total;
}

sum(1, 2, 3);    // 6
sum();           // 0

A function with no return gives back undefined.

The exercises

Each exercise has a file for your code and a test file you can read. Functions are shared with the tests through export:

export function greet(name) {
  return `Hello, ${name}!`;
}

Run them in the app, or in a terminal: python3 check.py js/01-functions

Common mistakes

  • == in place of ===.
  • Forgetting return. With braces, an arrow function returns nothing unless you say so.
  • console.log where a return was asked for.
  • Adding a number to a string. "5" + 1 is "51". Convert first with Number("5").
  • Leaving out export. The tests then cannot see your function.

Test yourself

First functions js/01-functions

Write four functions in solution.mjs and export each of them.

  • greet(name) returns Hello, NAME!. With no argument it returns Hello, world!.
  • isAdult(age) returns true when the age is 18 or more, otherwise false.
  • fizzbuzz(n) returns "FizzBuzz" if n is divisible by 15, "Fizz" if by 3, "Buzz" if by 5, and otherwise the number as a string, such as "7".
  • sum(...numbers) returns the sum of all its arguments, and 0 when there are none.

The functions return their result. They do not print.
