Install: what this track needs

Quick install

One command installs everything for this track. It skips what you already have.

Ubuntu, Debian, or Ubuntu inside WSL, from the zero2dev folder:

$ ./setup/install.sh --stack node

If something does not install, the script says why and offers to try again or to install it another way.

Windows, from an Administrator PowerShell in the setup folder (it installs WSL and Ubuntu first if needed):

powershell -ExecutionPolicy Bypass -File .\install.ps1 -Stacks node

macOS has no quick install script. Use the Homebrew commands below, or let Docker run what is missing.

Node.js and npm: by hand

Ubuntu, Debian, WSL:

$ curl -fsSL https://mise.run | sh
$ ~/.local/bin/mise use --global node@lts

macOS, with Homebrew:

$ brew install node

Check that it works:

$ node --version && npm --version

Or install nothing: with Docker running, the app runs JavaScript in the image node:22-slim (one download).

The vue packages come from npm, once: press Download packages on the Setup page, or run python3 check.py prefetch vue.

When the app is running, this box also shows what your machine already has.

This track builds on HTML, CSS and JavaScript.

What Vue is

Vue is a framework for building user interfaces out of components: small, reusable pieces that each own a bit of the page. You describe what the page should look like for the current data, and Vue keeps the page in step when the data changes.

It solves the same problem as React, with a different feel: Vue keeps HTML, JavaScript and CSS recognisable, in one file per component.

A single-file component

A component lives in a .vue file with up to three blocks:

<script setup>
const name = "Ada";
</script>

<template>
  <p class="hello">Hello, {{ name }}!</p>
</template>

<style scoped>
.hello { color: teal; }
</style>
BlockHolds
<script setup>the component's JavaScript. Every variable and function declared here can be used in the template.
<template>the HTML of the component, with Vue's additions
<style scoped>CSS that applies only to this component

Text: double braces

{{ }} puts the value of a JavaScript expression into the text:

<p>{{ name }} has {{ items.length }} items, total {{ price * 2 }}</p>

Vue escapes the value, so text from a user cannot inject HTML.

Attributes: v-bind

Braces do not work inside attributes. Use v-bind:, or its short form, a colon:

<img :src="photoUrl" :alt="name">
<a :href="site">Website</a>
<button :disabled="isSaving">Save</button>

With the colon, the value is a JavaScript expression. Without it, plain text.

Events: v-on

v-on:, or its short form @, runs code when something happens:

<button @click="count++">Add</button>
<button @click="save">Save</button>
<form @submit.prevent="send">...</form>

.prevent is a modifier: it calls preventDefault() for you, which stops a form from reloading the page.

Data that changes

An ordinary variable can be shown, but changing it does not update the page. Wrap it with ref to make it reactive:

<script setup>
import { ref } from "vue";

const following = ref(false);

function toggle() {
  following.value = !following.value;
}
</script>

<template>
  <button @click="toggle">{{ following ? "Following" : "Follow" }}</button>
</template>

In the script you read and write following.value. In the template you write just following: Vue unwraps it. The next lesson is all about this.

Using a component

Import it and use it as a tag:

<script setup>
import ProfileCard from "./ProfileCard.vue";
</script>

<template>
  <ProfileCard />
  <ProfileCard />
</template>

Each use is a separate copy with its own state.

Starting a real project

$ npm create vue@latest
$ cd my-app
$ npm install
$ npm run dev

That sets up Vite, which compiles .vue files and reloads the page as you save. The exercises of this track are prepared for you in the same way.

Common mistakes

  • Braces in an attribute: href="{{ site }}" does not work. Write :href="site".
  • Forgetting .value in the script, or writing it in the template.
  • A plain variable where a ref is needed. The page shows the first value for ever.
  • @click="save()" versus @click="save". Both work in Vue. With brackets you can pass arguments.

Test yourself

A profile card vue/01-profile-card

Finish ProfileCard.vue. The data is given in the script. Write the template.

  • An h2 with the name.
  • A paragraph with the class role and the text Role: followed by the role.
  • An img whose src is photo and whose alt is the name.
  • A link with the text Website whose href is site.
  • A button. It shows Follow. After a click it shows Following, and after another click Follow again. Use the following ref and the toggle function.
