Layout: flexbox, grid and sizing

The layout tools of CSS, as classes.

Everything here is flexbox and grid from the CSS track, written as classes.

The centred column

The most common layout on the web is a column with a maximum width, centred:

<main class="max-w-4xl mx-auto px-4">...</main>

max-w-4xl limits the width, mx-auto shares the remaining space left and right, and px-4 keeps the text off the edges on a small screen.

Space between children

gap works in flex and grid containers. For plain stacked elements there is space-y-4, which puts a margin between each child and the next:

<div class="space-y-4">
  <p>...</p>
  <p>...</p>
</div>

Common mistakes

  • justify-* and items-* with no flex or grid on the same element. They do nothing.
  • grid-cols-3 with no grid.
  • Classes on the wrong element. Layout classes go on the container, not on the items.
  • mx-auto with no width or maximum width. There is no space left to share.
  • Margins on items where gap on the container would do.

Test yourself

A header and a grid of cards tailwind/02-layout

Lay out the page in index.html with classes. Do not write any CSS.

  • The header is a flex row: flex, with the items centred across (items-center) and pushed to both ends (justify-between). It has the padding p-4.
  • The nav is also flex, with a gap-4 between the links.
  • The main is a centred column: max-w-4xl, mx-auto, and the padding p-4.
  • The element with the id cards is a grid of three columns: grid, grid-cols-3, with gap-6.
  • The first card, with the id featured, is two columns wide: col-span-2.
